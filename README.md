# ManualCam 手动相机

把 iPhone 变成一台可以像单反一样手动操作的相机：快门、ISO、对焦、白平衡全部自己控制，支持 RAW、慢门、虚化、包围曝光和间隔拍摄。

纯 Swift + SwiftUI + AVFoundation 实现，**没有任何第三方依赖**，用 Xcode 打开就能装到自己的 iPhone 上。

> 本项目没有上架 App Store，需要用自己的 Apple ID 通过 Xcode 安装（免费账号即可），步骤见下方[自己部署](#自己部署)。

## 功能一览

### 手动曝光

| 功能 | 说明 |
|---|---|
| 四种曝光档位 | ISO 和快门各有独立的「自动」开关，组合出 **P / S（快门优先）/ ISO 优先 / M** 四档，左上角显示当前档位 |
| 单反式刻度 | 快门（1/8000 起）和 ISO 按 1/3 档跳档，每跳一档轻震；可调范围随镜头硬件自动变化 |
| 曝光补偿 | P / S / ISO 优先档下 EV 可调；M 档下这一行变成**测光表**，显示当前参数离正确曝光差几档 |
| 手动对焦 | 对焦滑杆 + **对焦放大镜**（拖动时弹出约 4~5 倍局部放大）+ 峰值对焦（合焦处红色描边） |
| 白平衡 | 色温 2500–9000K + 色调（绿 ↔ 品红）；**吸管**点白纸或灰卡一键校准 |
| 点击对焦 | 点屏幕任意位置对焦（P 档下同时测光），手动曝光不会被点击冲掉 |

### 拍摄模式

| 模式 | 说明 |
|---|---|
| 照片 | 可选 **HEIF / RAW / ProRAW**。RAW 与调色后的 HEIF 作为同一张照片存入相册；ProRAW 用传感器满像素（4800 万像素机型 8064×6048） |
| 慢门 | 1–30 秒多帧合成长曝光。**流水**（平均，拉丝效果）/ **光轨**（取最亮，车轨光绘）/ **夜景**（对齐后降噪）。支持手持逐帧对齐，取景器实时显示合成过程 |
| 虚化 | 模拟光圈 f/1.4–f/16，取景器**实时预览**。有双摄的机型用深度数据（与系统人像同款算法），否则用 AI 识别主体（人、宠物、物体都行） |
| 包围 | 一次拍 -x / 0 / +x 三张（±0.7 到 ±3 EV），手持自动对齐后合成一张 HDR |

### 驱动方式

单拍、**按住连拍**（最多 30 张）、自拍 3 秒 / 10 秒、**间隔拍摄**（2–60 秒间隔，10–300 张或不限），间隔拍摄可同时叠加生成**星轨**。

### 辅助与便利

- 实时 RGB 直方图、斑马纹（过曝提示）、三分线网格、水平仪
- 4 个内置色调 + 导入任意 `.cube` 3D LUT，预览和成片一致
- 超广角 / 广角 / 长焦切换，双指变焦；**每个镜头记住**各自的对焦和曝光参数
- **自定义档 C1 / C2 / C3**：一键保存、调用整套参数
- **实体按键**：音量键当快门（按住可连拍）；iPhone 16 及以后的「相机控制」键可轻滑调快门、ISO、EV、变焦、光圈、模式
- **横拍**：按手机实际朝向保存照片方向（含 RAW），图标跟着转
- **App 内相册**：只显示本 App 拍的照片，可放大到 100 倍，ⓘ 查看快门、光圈、ISO、焦距、镜头等拍摄参数
- 所有照片保留完整 EXIF

## 自己部署

### 1. 获取代码

```bash
git clone https://github.com/arnieChan/ManualCam.git
cd ManualCam
open ManualCam/ManualCam.xcodeproj
```

### 2. 配置签名

在 Xcode 左侧选中 **ManualCam** 工程 → **TARGETS → ManualCam** → **Signing & Capabilities**：

1. 勾选 **Automatically manage signing**
2. **Team** 选择你自己的 Apple ID（没有的话点 *Add an Account…* 登录）
3. 把 **Bundle Identifier** 改成你自己的唯一值，例如 `com.你的名字.ManualCam`。原来的 ID 属于作者的开发团队，不改会签名失败

### 3. 准备 iPhone

1. 用数据线连接 iPhone 和 Mac，在手机上点「信任此电脑」
2. 打开开发者模式：**设置 → 隐私与安全性 → 开发者模式**，打开后手机会重启
3. 在 Xcode 顶部的设备列表里选中你的 iPhone

### 4. 运行

点 Xcode 左上角的 ▶︎（或按 `⌘R`）。第一次安装后，如果手机提示「不受信任的开发者」：

**设置 → 通用 → VPN 与设备管理** → 选中你的 Apple ID → **信任**

再次打开 App，允许相机和照片权限即可使用。

### 免费账号的限制

用免费 Apple ID 签名的 App **7 天后会失效**，到期后重新连上 Mac 在 Xcode 里再运行一次即可（照片和设置不会丢）。付费开发者账号签名有效期一年，还可以用 TestFlight 无线分发。

### 只想检查能否编译（不签名）

```bash
xcodebuild -project ManualCam/ManualCam.xcodeproj -scheme ManualCam \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

## 使用说明

**界面布局**

- **顶部第一行**：色调菜单、拍摄格式（照片模式下）、驱动方式、峰值对焦、直方图
- **顶部第二行**：曝光档位标识、自定义档「C」、斑马纹、网格、水平仪、镜头切换
- **底部参数面板**：对焦、ISO、快门、EV、当前模式的专属参数、白平衡。点面板上方的横条可以收起，让取景器不被挡住
- **底部**：模式切换（照片 / 慢门 / 虚化 / 包围）、快门键、左侧缩略图（点开 App 内相册）

**几个常用场景**

| 想拍 | 怎么设 |
|---|---|
| 运动中的人或宠物 | 关闭快门自动，设 1/500 或更快（S 档），ISO 会自动补偿 |
| 夜景人像 / 弱光不想噪点 | 慢门模式 →「夜景」→ 2–4 秒，手持即可 |
| 瀑布、溪流拉丝 | 慢门模式 →「流水」→ 2–8 秒，有三脚架更好 |
| 车灯光轨 | 慢门模式 →「光轨」→ 4–15 秒，上三脚架 |
| 逆光、窗边室内 | 包围模式 → 档距 ±2 → 打开「合成 HDR」 |
| 星轨 | 照片模式 → 驱动选「间隔拍摄」→ 打开「星轨」，上三脚架 |
| 偏色的室内灯光 | 白平衡行点吸管，再点画面里的白纸 |

## 技术实现

| 文件 | 作用 |
|---|---|
| `CameraManager.swift` | 核心：AVCaptureSession、手动曝光 / 对焦 / 白平衡、半自动曝光闭环、拍摄流程、预览帧处理 |
| `CameraView.swift` | 拍摄界面 |
| `ExposureStops.swift` | 快门 / ISO / 光圈的 1/3 档刻度 |
| `LongExposureEngine.swift` | 慢门：32 位浮点缓冲区逐帧平均或取最亮 |
| `BracketEngine.swift` | Vision 帧对齐、手动包围参数、曝光融合 HDR |
| `BokehEngine.swift` | 虚化：`CIDepthBlurEffect`（深度）/ Vision 前景分割 + 可变模糊 |
| `PhotoSaver.swift` | HEIF 编码并写回 EXIF、RAW + HEIF 组合存入相册 |
| `CaptureControls.swift` | 音量键快门、相机控制键拨盘 |
| `CameraPresets.swift` | 自定义档 C1 / C2 / C3 |
| `GalleryView.swift` | App 内相册与拍摄参数面板 |
| `DeviceOrientation.swift` | 用重力传感器判断手机朝向（不受竖排方向锁定影响） |
| `ToneEngine.swift` / `LUTEngine.swift` | 内置色调、`.cube` 解析与 LUT 烘焙 |
| `LevelManager.swift` | 水平仪 |

几个实现上的要点：

- **S 档和 ISO 优先档**：AVFoundation 只有全自动和全手动，半自动档是读取 `exposureTargetOffset` 后自己闭环调整自动的那一项（约每秒 5 次，带阻尼防振荡）
- **慢门超过 1 秒**：iPhone 单帧快门硬件上限约 1 秒，更长的曝光由连续预览帧合成，所以分辨率等于预览帧分辨率
- **HDR 归一化**：用预乘 alpha 完成「加权和 ÷ 权重和」，只用系统内置的 Core Image 滤镜，不需要编译 Metal 着色器
- **数据都在本机**：自定义档、镜头记忆、导入的 LUT 存在 App 本地；App 不联网，不收集任何数据

## 已知限制

- iPhone 的光圈是物理固定的，「光圈」只控制后期合成的虚化强度，不改变真实景深和进光量
- 慢门合成照片的分辨率等于预览帧分辨率，不是传感器满像素
- HDR 是单尺度曝光融合，大面积渐变（如天空）上可能有轻微的明暗不连贯
- 只支持后置摄像头；界面固定竖屏（横拍时照片方向正确，但参数面板不横排）
- RAW 只保存 DNG 原片，App 内不做 RAW 显影，需要用 Lightroom 等软件处理
- 未做视频录制
